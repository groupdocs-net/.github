## GroupDocs .NET - Document Processing Plugins 👋

Welcome! This GitHub organization hosts the code examples and tooling for the **GroupDocs .NET** document processing plugins.

> GroupDocs .NET plugins are lightweight, single-task .NET libraries for document conversion and merging. They run on Windows, macOS, and Linux, work fully on-premise, and are distributed via NuGet.

### Purpose of this organization

- Host the official **code examples** for the .NET plugins in C#, VB.NET, and F#. They are generated from the documentation, so they match its code samples.
- Build every example on Linux and Windows with GitHub Actions.
- Keep the examples up to date with new package versions.

---

### Organization conventions

**Repository naming**
- `groupdocs-<product>-lowcode-examples-csharp` — C# code examples
- `groupdocs-<product>-lowcode-examples-fsharp` — F# code examples
- `groupdocs-<product>-lowcode-examples-vbnet` — VB.NET code examples

**Branching**
- `main` — the published code examples.

**Versioning**
- Package versions follow the release date: year and month, for example `26.9.0`.
- Each code example repository is tagged with the package version it targets (e.g. `26.9.0`).
